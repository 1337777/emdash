## The proposed generator cut

Let P:Prof(A,B), Q:Prof(B,X), O:Prof(A,X), and let
`k : ProfMap(P tensor Q,O)` be arbitrary. For H:B'->B define the two actual
pullbacks P_H and Q_H. Given shaped inputs r,s meeting at m:I->B', the proposed
rule is

```text
apply(eval(reindex(lambda(k), id_A,H)), tensor_intro(m,r,s))
    = apply(k, tensor_intro(H o m,r,s)).
```

The inputs r,s have precisely the original P/Q shaped types at H o m;
the existing nested-reindex rule identifies these with their P_H/Q_H types
on the left. Actual k,H,m,r,s are retained. Perturbing r is tested negatively.

This is a computation candidate for a reindexed lambda/evaluation cut at
`Prof_cell_apply`, using the existing tensor introduction. It is motivated
by evaluation on the same generator after middle-variable substitution.
It does **not** identify the two tensor objects globally: changing the middle
category is only used inside this particular application. Nor is the rule
a theorem already derivable from the opaque map-level eval/lambda beta/eta
interface. The unextended generic boundary records the exact missing cut;
subject reduction, its independent consumer and interactions must be checked
before selecting the candidate.

For the actual canonical raw counit, specialize
P=Q=O=Unit_B, k=coyoneda_cov(Unit_B), and H=F. The right side then reaches an
existing co-Yoneda redex. With the second generator
`Prof_func_hom(F o m)`, that existing beta returns arbitrary shaped p. This
uses the actual lambda/co-Yoneda counit body, not `eval(id_Conjoint)` and not
a postulated triangle comparison.
